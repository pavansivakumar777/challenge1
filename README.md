Challenge1 - marks calculator for calculating marks 
PROBLEM Statement: to build a c program to read the marks of a student and calculate  the total marks, average marks and percentage. 
Algorithm:
Start
Create variables for 5 subject marks, total, average, percentage.
Read the marks of 5 subjects by using scanf function.
Calculate the total = sub1+sub2+sub3+sub4+sub5
Calculate the average = total/5.
Calculate the percentage = (total/500)*100.
Print total, average and percentage.
Stop
